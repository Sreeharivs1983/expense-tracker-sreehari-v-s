# Expense Tracker

A simple expense tracker web application built using HTML, CSS, and JavaScript.

## Features

- Add income and expense transactions
- Enter amount, category, date, and description
- Edit existing transactions
- Delete transactions
- View total income
- View total expenses
- View current balance
- Filter transactions by income or expense
- Filter transactions by category
- Store transactions using browser Local Storage
- Monthly income and expense summary
- Category wise expense chart
- Input validation and error messages
- Responsive design for desktop and mobile devices

## Technologies Used

- HTML5
- CSS3
- JavaScript

## How to Run

1. Clone the repository to your local computer:

   `git clone https://github.com/Sreeharivs1983/expense-tracker-sreehari-v-s.git`

2. Navigate to the project folder:

   `cd expense-tracker-sreehari-v-s`

3. Open `index.html` in any modern web browser.


The application runs directly in the browser and does not require any additional installation, dependencies, or build steps.
